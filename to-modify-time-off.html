Modify Time Off Request

How to modify an approved time-off request in UKG Ready

Before You Begin How to Modify
Important

Before You Begin

There is one rule you must follow before attempting to modify.

📍 Corporate and DC employees only
🚫
You cannot modify a time-off request until it has been approved. If your request hasn't been approved yet, you must cancel it and re-submit a new request instead.
Process

How to Modify an Approved Request

Follow each step in order.

1

Go to Your Current Timesheet

Navigate to Menu ☰ > My Info > My Time > Timesheet > Current Timesheet.

2

Select the Applicable Date Period

Find and select the date(s) for the request you want to modify.

3

Select Change Request > Modify Time Off

Click Change Request, then select Modify Time Off.

4

Select and Modify the Date

Select the date you originally requested off and make your changes.

5

Click Submit

Click Submit to send the modification through.
