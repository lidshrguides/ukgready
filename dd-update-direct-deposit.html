Overview

Managing Your Bank Accounts

All direct deposit changes are made through My Tasks in UKG Ready — not from the Direct Deposit view screen.

⚠️
Important: The Direct Deposit screen (under My Pay) is view only. All changes must be made through My Tasks → Update My Information → Add Direct Deposit.
🚫
There is no Delete option. To remove or replace an account, you end-date it by setting an Active To date. See the Replace / Switch Banks section for how to do this correctly.
🚫
Never change the Effective From or Active From date on an existing active account. Only set dates when you are intentionally end-dating an old account or activating a new one.

Scenario 1
🏦

Add Your Initial Account

Use this if you are setting up direct deposit for the first time and have no existing accounts on file.

1

Navigate to My Tasks

  • From the home page, click My Tasks
  • Select Update My Information
  • Click Start next to Add Direct Deposit
2

Add Your Account

  • Click + Add
  • Fill in: Name, Account Type, Account Number, Routing Number
  • Set Calculation Method to Entire/Remainder
  • Do not change the Active From date — it will auto-populate
3

Save & Submit

  • Click Save, then click Submit
Scenario 2
➕

Add a Second Account

Use this to split your paycheck between two accounts — like sending a fixed amount to savings and the rest to checking.

1

Navigate to My Tasks

  • From the home page, click My Tasks
  • Select Update My Information
  • Click Start next to Add Direct Deposit
2

Add the New Account

  • Click + Add
  • Fill in: Name, Account Type, Calculation Method, Account Number, Routing Number
  • Do not change the Active From date — it will auto-populate
3

Set the Calculation Method

  • Flat $ Amount — sends a fixed dollar amount to this account first (e.g., $100 to savings)
  • Percentage — sends a set percentage of each paycheck
  • Your existing main account must stay set to Entire/Remainder so the rest of your pay deposits there

Example: $600 Paycheck

Account 1 — Flat $100 (new savings account)$100.00
Account 2 — Entire/Remainder (existing checking)$500.00
4

Save & Submit

  • Click Save, then click Submit
Scenario 3
🔄

Replace / Switch Banks

Use this when you're closing an old account and moving to a new one. Since there's no delete option, you end-date the old account and add the new one in the same submission.

💡
Both steps happen in the same submission — end-date the old account and add the new one before clicking Submit. Don't submit after each step separately.
1

Navigate to My Tasks

  • From the home page, click My Tasks
  • Select Update My Information
  • Click Start next to Add Direct Deposit
2

End-Date the Old Account

  • Click the ⋯ next to your existing account and select Edit
  • Set the Active To date to yesterday's date
  • Click Save — do not Submit yet
⚠️
Use yesterday's date for the Active To field. This closes the old account at end of day yesterday, so the new account is active starting today with no gap in coverage.
3

Add the New Account

  • Click + Add
  • Set the Active From date to today's date
  • Fill in: Name, Account Type, Account Number, Routing Number
  • Set Calculation Method to Entire/Remainder

✅ Old Account

  • Active To = yesterday's date

✅ New Account

  • Active From = today's date
4

Save & Submit

  • Click Save, then click Submit — both changes process together
Reference

Key Rules to Remember

Keep these in mind any time you update direct deposit.

🚫
There is no Delete option. To stop using an account, set an Active To date (yesterday's date) to end-date it. Then add your new account with today's date as the Active From.
🚫
Never change the Effective From or Active From date on an existing active account. Only use date fields when intentionally end-dating an old account or setting up a new one.
⚠️
One Entire/Remainder account is always required. Every setup must have exactly one account set to Entire/Remainder — this is where the balance of your pay deposits after any flat-amount or percentage accounts are funded.
📋
Account order matters when splitting pay. UKG Ready processes accounts in the order listed — the flat amount or percentage account is funded first, and the Entire/Remainder account receives the rest.
✅
Always Submit, not just Save. Saving stores your changes as a draft — nothing takes effect until you click Submit.

Questions about direct deposit?

Reach out to your HR team if a change doesn't take effect as expected or if you need help with your bank info.
