How to Demote
an Employee

A step-by-step reference for processing employee demotions in UKG Ready

When to Use 2 Ways to Access Before You Begin Step-by-Step After You Submit
Overview

When to Use This Guide

Use the Demote Employee HR Action when all of the following apply.

✓ Use when

  • Employee is moving to a lower position
  • A new position assignment is required
  • Pay may decrease

✕ Do NOT use for

  • Pay changes only
  • Job title changes only
Navigation

2 Ways to Access

Use the Quick Access method whenever possible — it's fewer clicks.

Setup

Before You Begin

Two critical rules before touching anything in the form.

🚫
Do NOT change the Effective From Date. This field auto-populates and must stay as-is.
⚠️
Always click the correct employee. Search by name or use the magnifying glass icon to browse.
Process

Step-by-Step

Follow each step in order — skipping ahead can cause errors.

1

Add New Position Assignment

  • Click +Add under Position Assignment
  • Select the new position
  • Enter Start Date (demotion date)
  • Check Is Primary Assignment
  • Set Assignment Change Reason = Demotion
🚫
Do not enter an End Date. Do not change Compensation here. FTE must stay at 1.
2

Confirm Reporting Structure

  • Select Directly Reports to Manager
  • If blank, click Cancel and leave it blank
  • Click Save
  • Click Yes when prompted
ℹ️
System will automatically end-date the current position and add the new one.
3

Confirm Job Information

FieldActionStatus
Default JobShould auto-fill — verify it's correctAuto-fill
Employee TypeShould auto-fill — verify it's correctAuto-fill
Pay TypeShould auto-fill — verify it's correctAuto-fill
Manager 1Manually assign the employee's managerRequired
Status Change DateSet to the demotion dateRequired
4

Add New Compensation

  • Click +Add — do NOT edit the existing record
  • Enter Compensation Effective Date
  • Select Reason Code = Demotion
⚠️
If reason code isn't Demotion, you should not be using this HR Action. Contact hr@lids.com.
5

Enter Pay Details

  • Hourly: Enter amount Per Hour
  • Salary: Enter amount Per Year
🚫
Do not change Hours, Pay Periods per Year, or Autopay Type.
6

Save & Submit

  • Click Save
  • Click Submit
